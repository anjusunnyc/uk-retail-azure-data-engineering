# Synapse Spark Notebook

The Project 1 Spark transformation notebook belongs in this folder as:

`01_silver_data_processing.ipynb`

It implements the Bronze-to-Silver processing for transactions, products, customers, and inventory, including profiling, cleansing, validation, transaction classification, and Parquet output to the Silver layer.

The original notebook is intentionally kept separate from generated SQL scripts so the repository reflects the actual Synapse architecture.
